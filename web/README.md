# 관리 화면 (web/)

에이전트가 준비한 메일과 전화를 사람이 확인하고 승인하는 화면입니다. 배포된 백엔드 API(`docs/frontend-handoff.md`)만 부릅니다.

## 실행

```bash
cd web
npm install
npm run dev          # http://localhost:5173  (백엔드 CORS에 허용된 주소)
```

- 로그인: 이름과 관리자 비밀번호 (비밀번호는 팀원에게 따로 받습니다. 저장소에 적지 않습니다)
- 서버 없이 보려면 `http://localhost:5173/?mock=1` 또는 로그인 화면의 "서버 없이 시연 데이터로 보기"
- 로컬 백엔드를 쓰려면 `web/.env.local`에 `VITE_API_BASE=http://localhost:8000`
- 시험: `npm test` (모의 서버 규칙과 승인·전화 패널 동작), 형 검사: `npm run typecheck`, 빌드: `npm run build`

## 디자인 두 안

| | A. 업무함 `/a` | B. 관제 센터 `/b` |
|---|---|---|
| 구성 | 왼쪽 메뉴, 목록과 상세 2단 | 파이프라인 단계 막대, 전화 카드, 고객 보드, 에이전트 활동, 오른쪽 서랍 |
| 첫 화면 | 오늘 할 일 요약(승인·전화·확인 필요) | 파이프라인 전체와 지금 걸 전화 |
| 잘 맞는 상황 | 아침에 쌓인 일을 빠르게 처리 | 전체 흐름 설명, 시연, 감독 |
| 단축키 | J/K 이동, A 승인, E 수정, R 반려 | Esc로 서랍 닫기 |

화면 안의 "디자인 B로 보기" / "디자인 A로 보기" 링크(A는 왼쪽 메뉴 아래, B는 위쪽 오른쪽)로 바꿀 수 있고, 마지막에 본 디자인을 기억합니다.
공통 부분은 `src/components/`(승인 패널, 전화 패널, 고객 상세, 에이전트 기록, 리드 올리기, 평가 지표)에 있고, 디자인별 화면은 `src/designs/a`, `src/designs/b`에 있습니다.

## 화면 목록

| 화면 | 하는 일 |
|------|--------|
| 오늘 할 일 (A) / 관제 (B) | 승인·전화·확인 필요 건수와 에이전트 활동 |
| 승인 대기 | 메일 근거, 선별 근거, 발송 전 점검(광고 표시, 수신 거부, AI 고지, 근거에 없는 수치)을 보고 승인·수정·반려 |
| 전화 | 콜 스크립트를 읽고 통화 결과 기록 |
| 답장함 | 고객 답장과 에이전트의 분류, 확신도, 사람 확인 필요 여부 |
| 확인 필요 | 에이전트가 판단하지 못한 고객 처리 (수신 거부 확정, 인계) |
| 리드, 고객 상세 | 이력, 조사 사실(출처 링크), 다음 할 일 안내, 시연 도구 |
| 에이전트 기록 | 에이전트가 어떤 도구를 왜 골랐는지 단계별로 확인 |
| 승인 이력 | 누가 언제 무엇을 승인·수정·반려했는지, 수정 내용 비교, CSV |
| 승인 자료 | 에이전트가 근거로 쓸 수 있는 회사 자료 전체 |
| 평가 지표 | 지표, 수작업 기준 시간 입력, CSV |
| 리드 올리기 | CSV·엑셀·구글 시트, 미리보기 후 저장 |
| 설정·상태 | 운영 원칙, 발송 모드, 모델 키, 발송 상한, Slack 연결 상태와 연결 시험, 수신 거부 명단 |

어디서든 `/` 또는 Ctrl+K로 회사를 검색해 바로 열 수 있습니다.
답장함, 승인 이력, 승인 자료, 설정·상태는 백엔드 최신 버전(`/admin/replies`, `/admin/approvals`, `/admin/kb`, `/admin/status`)이 배포되어야 실서버에서 보입니다. 그 전에는 "아직 서버에 배포되지 않았습니다"라고 알려 줍니다.
## 지키는 규칙

- 고객에게 나가는 행동은 "승인·발송" 버튼으로만 일어납니다. 자동 발송 기능은 없습니다.
- 점수는 근거 태그와 함께, 조사한 사실은 출처 링크와 함께 보여 줍니다.
- AI가 쓴 초안과 스크립트에는 "AI 초안", "AI 스크립트" 표시가 붙습니다.
- 시각은 한국 시간으로 보여 줍니다.
- 시연 도구(리서치·초안·인계·모의 답장 실행)는 LLM 비용이 들기 때문에 한 번 더 확인한 뒤 실행합니다.

## Slack 알림 링크

Slack 알림의 버튼과 링크는 `ADMIN_WEB_URL` 뒤에 `/m/{메일 id}`(메일 검토), `/l/{리드 id}`(고객), `/c/{전화 id}`(전화)를 붙입니다. 화면이 이 주소를 지금 쓰는 디자인의 상세 화면으로 보냅니다.

## 배포

정적 파일이므로 Vercel 같은 곳에 올립니다 (`vercel.json`에 단일 페이지 앱용 rewrite 포함). 올린 주소를 백엔드 `ALLOWED_ORIGINS`에 추가하고 `scripts/sync_secrets.sh`로 반영해야 브라우저에서 API를 부를 수 있습니다. 같은 주소를 `ADMIN_WEB_URL`에도 넣습니다.
