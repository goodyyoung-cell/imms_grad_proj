# 노바데스크 가격 정책 (가상)

> 연구용 가상 가격이다. 부가세 별도.

## 플랜

- 스타터: 상담원 1인당 월 29,000원. 통합 문의함, AI 답변 초안 월 1,000건, 기본 대시보드.
- 비즈니스: 상담원 1인당 월 59,000원. AI 답변 초안 무제한, 자동 분류·배정, Slack 알림, 카카오톡 채널 연동.
- 엔터프라이즈: 별도 견적. API 연동, 전담 매니저, SSO, 데이터 보관 기간 조정.

## 무료 체험

모든 신규 고객은 14일 무료 체험을 쓸 수 있다. 체험 기간에는 비즈니스 플랜 기능을 모두 쓴다. 카드 등록은 필요 없다.

## 할인

- 연간 결제 시 월 요금의 15% 할인
- 상담원 20인 이상은 영업 담당자와 협의 (할인율을 SDR이 약속하지 않는다)

## SDR이 지킬 것

- 위에 적힌 가격과 체험 조건만 말한다.
- 추가 할인, 맞춤 견적, 계약 조건은 약속하지 않고 담당 AE에게 넘긴다.
