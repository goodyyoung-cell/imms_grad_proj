### 2026-11-26: 첫 메일 발송 1시간 뒤 전화 팔로업과 콜 스크립트
- 결정: 첫 메일이 승인·발송되면 **발송 1시간 뒤**(평일 9~18시 밖이면 다음 평일 9시) 전화 팔로업 과제와 콜 스크립트를 자동으로 만든다.
  - 목적: ① 메일 수신 확인 ② 미팅 희망 시기 ③ 고객사의 **Compelling Reason**(왜 지금 바꿔야 하는가: 계기·영향·미해결 비용·기한·반길 사람) 찾기.
  - 스크립트는 에이전트가 쓴다 (내부 준비 자료라 자율). 근거 규칙은 메일 초안과 같고, 통화 허락·녹음 동의·연락 거부 시 종료 문구는 코드가 넣는다. 키가 없으면 기본 스크립트.
  - **전화는 SDR이 직접 건다.** 인터넷·유선 전화와 연동하지 않는다. 콜 과제는 SDR의 할 일 목록이다.
  - **시스템이 콜 과제를 취소하는 경우는 수신 거부 하나뿐**(DB 트리거). 답장이 오거나 인계되면 취소하지 않고, 통화 전에 볼 수 있게 과제에 알림을 붙인다.
  - SDR은 통화 결과와 함께 메일 수신 여부, 희망 미팅 시기, Compelling Reason을 기록한다. 관심이면 인계되고, 인계 요약에 이 내용이 들어간다. 이미 인계된 리드는 통화 결과로 상태를 되돌리지 않는다.
- 이유: 메일만 보내고 전화 팔로업이 없으면 영업기회 전환율이 떨어진다. 메일 직후 짧은 통화가 수신 확인과 관심 확인에 효과적이다.
