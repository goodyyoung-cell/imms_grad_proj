# 주요 결정 기록

Claude와의 대화는 팀원끼리 공유되지 않습니다. 대화나 회의에서 내린 중요한 결정은 여기에 남겨서, 두 사람과 각자의 Claude가 같은 전제로 작업하도록 합니다.

새 결정은 맨 위에 추가합니다. 결정이 바뀌면 기존 항목을 지우지 말고 "대체됨"으로 표시한 뒤 새 항목을 씁니다.

## 템플릿

```

- 검토한 대안: 고려했지만 택하지 않은 것
- 상태: 확정 / 검토 중 / 대체됨
```
