# 프로젝트 계획서 요약

2026년 가을학기 초(제출기한 9월 23일)에 제출한 정보경영프로그램 현장연구 프로젝트 계획서의 내용을 정리한 문서입니다.
원본 계획서에는 개인정보가 포함되어 있어 저장소에는 올리지 않습니다.

## 주제

SaaS·AI 솔루션 영업의 확장성과 표준화를 위한 도메인 특화 AI SDR 에이전트 설계 및 프로토타입 개발

## 주제 선정 배경

- SaaS·AI 솔루션 활용이 대기업 중심에서 중소기업으로 확산되며 잠재 고객층과 시장 범위가 넓어지고 있다.
- 그러나 SDR 업무는 직접 고용 또는 외주 인력에 의존하는 노동집약적 구조여서, 인원과 비용에 따라 고객 접촉 범위가 제한된다.
- 담당자별 역량 차이로 접촉 빈도, 메시지 적합성, 상담 품질, 후속 대응의 일관성에 편차가 생긴다.
- 연구자들의 SaaS·AI 솔루션 영업 실무 경험을 바탕으로, 영업 지식과 고객 선별 기준을 반영한 AI SDR 에이전트를 설계한다.
- AI는 초기 영업 단계(Top of Funnel)의 반복적인 접촉·응대·선별을, 인간 SDR은 선별된 고객의 심층 상담과 영업기회 구체화를 맡는다.
- 이를 통해 인력 증원에만 의존하지 않는 고객 커버리지 확대와 영업 품질 표준화 가능성을 탐색한다.

## 프로젝트 구성

5개 기능을 연결하는 프로토타입과 운영·평가 체계로 구성한다.

1. **고객 리서치·선별**: 기업·산업 정보와 솔루션 적합성을 파악하고 접촉 우선순위를 제안한다.
2. **이메일 소통**: 고객별 메시지를 생성하고 일정에 따른 발송, 답장 분류, 후속 응대를 수행한다.
3. **초기 스크리닝 콜**: 이메일의 CTA를 화상 미팅 예약으로 연결하고, AI가 초기 질문·응답으로 도입 수요를 확인한다.
4. **인간 SDR 인계**: 고객 리서치, 접촉 이력, 관심사, 선별 근거, 권장 후속 조치를 요약해 제공한다.
5. **모의 콜·코칭**: 고객 상황을 반영한 역할극과 피드백으로 인간 SDR의 실제 상담 준비를 지원한다.

## 주요 연구 내용

### 1. 현업 프로세스 분석 및 영업 지식의 구조화

- 중소기업 대상 SaaS·AI 솔루션 영업을 연구 범위로 설정한다.
- 기존 고객 발굴·응대·인계 절차의 병목과 반복 업무를 정리한다.
- 실무 경험과 영업 담당자 의견을 토대로 고객 유형, 주요 질문, 반대 의견 대응, 유망 고객 판단 기준을 구조화한다.
- 범용 챗봇이 아니라 실제 SDR의 판단과 업무 흐름을 반영한 에이전트를 지향한다.

### 2. 도메인 특화 에이전트 및 고객 접점 구현

- LLM에 영업 지침, 제품 지식, 승인된 자료를 연결하고 프롬프트 설계와 RAG로 응답의 정확성과 일관성을 높인다.
- 파인튜닝은 학습데이터 확보와 필요성 검토를 거쳐 후속 고도화 방안으로 다룬다.
- 이메일 발송 일정과 답장에 따른 상태 전환을 구현한다. 수신 거부 시 자동 중단하고, 판단이 불명확하면 인간에게 이관한다.
- Teams·Google Meet 등의 연동 가능성을 검토하되, 초기 구현은 한 개 플랫폼 또는 모의 미팅 환경으로 한정한다.
- 스크리닝 콜에서 도입 목적, 현재 사용 환경, 의사결정 구조, 도입 시점을 확인하고 대화 결과를 정리하는 흐름을 구현한다.
- 플랫폼 연동과 실시간 음성 응대의 기술적 제약을 검토해 학기 내 구현·검증 가능한 범위를 정한다.

### 3. 고객 선별 및 인간 SDR 협업 설계

- 고객의 필요성, 솔루션 적합성, 구매 준비도 등을 공통 기준으로 평가하고 점수와 판단 근거를 함께 제시한다.
- 유망 고객과 추가 확인이 필요한 고객을 구분해 인간 SDR에게 전달하되, 최종 영업기회 등록·추진 여부는 담당자가 판단한다.
- 초기 접촉부터 인계까지의 고객 여정과 기업 리서치를 통합한 요약 자료를 제공한다.
- 해당 고객을 가정한 모의 콜에서 질문의 적절성, 경청, 반대 의견 대응, 다음 단계 합의에 대한 피드백을 제공한다.

### 4. 프로토타입 평가 및 현업 적용 가능성 검토

대표 고객 시나리오를 구성해 기존 수작업 방식과 AI 보조 방식을 동일 조건에서 비교한다.

| 평가 항목 | 측정 방식 |
|-----------|-----------|
| 고객당 처리 시간 | 시나리오별 소요 시간 비교 |
| 일정 시간 내 대응 가능 고객 수 | 동일 시간 내 처리량 비교 |
| 응답의 정확성·일관성 | 승인 자료 대비 정확도, 반복 실행 시 편차 |
| 선별 결과 일치도 | 실무자 판단과 AI 선별 결과 비교 |
| 인계 자료의 유용성 | 실무자 평가 |
| 모의 콜의 상담 준비 도움 정도 | 실무자 피드백 |

- 실제 회신율·미팅 전환율은 승인된 파일럿이 가능한 경우에만 보조 지표로 활용한다.
- 모의 실험 결과를 실제 매출 성과로 일반화하지 않는다.

### 5. 운영 원칙 및 기대 산출물

- 공개 정보와 가상·비식별 데이터를 우선 활용하고, 실제 고객 접촉은 회사 승인과 관련 규정 준수를 전제로 한다.
- AI 사용 사실 고지, 녹음·전사 동의, 개인정보 최소 수집, 접근 권한, 인간 검토 절차를 설계에 반영한다.
