# 샘플 데이터

## leads.json: 평가용 리드 12건

- **회사는 실제 회사**(공개 정보로 리서치 품질을 평가하기 위해), **담당자·연락처·문의 메모는 모두 가상**이다.
  메모에 적힌 문의 내용은 해당 회사의 실제 상황이 아니다.
- 이메일은 `.example` 도메인(예약 도메인)이라 어디로도 발송될 수 없다. 실제 회사 도메인은 `company_domain`(리서치용 홈페이지)에만 쓴다.
- 산업군: 이커머스(쿠팡), 물류(CJ대한통운), 여행(하나투어), IT 플랫폼(네이버), 식품(농심), 항공(대한항공), 뷰티(아모레퍼시픽), 자동차(현대자동차), 제약(유한양행), 통신(LG유플러스)
- 일부러 넣은 까다로운 경우
  - 중복: L06(같은 회사 다른 담당자), L07(L02와 같은 사람, 이메일 대소문자·회사명 표기만 다름) → `merged_into_key`
  - 직급 표기: CS팀장, 본부장, 매니저, 프로, Head of CS, 책임, 실장 등 (수평 호칭은 "직급 확인 필요")
  - 유입 경로와 경과일이 다양함

DB에 넣기: `python -m sdr_agent.cli seed`

## replies.json: 정답이 달린 모의 답장 24건

7개 분류(interested, question, not_now, not_decision_maker, out_of_office, unsubscribe, unclear)에 대한 정답 라벨.
근거 없는 질문(R06), 질문+미팅 의사(R21), '스팸'이 들어 있지만 수신 거부가 아닌 답장(R22) 같은 경계 사례를 포함한다.

정확도 측정: `python -m sdr_agent.cli eval-replies`
